# dsh-screenshot

A DeepSeek Harness bundle that adds a screenshot button (and `Ctrl+Shift+S`) to
the composer: it captures the whole desktop through a native full-screen region
picker, then lets you annotate and copy or download the result.

**Windows only.** The picker is a small .NET helper compiled on first use with
the framework's `csc.exe` (shipped with Windows).

## Features

- Composer camera button and `Ctrl+Shift+S`.
- Full-screen, always-on-top region picker (WeChat-style): drag anywhere,
  including over other applications and other monitors; `整屏 / 完成 / 取消`
  are drawn on the overlay itself. Enter confirms, Esc or right-click cancels.
- Optional: minimize the Harness window while capturing (default on), so the
  frozen screen never contains the app itself.
- Annotation editor in the preview: rectangle outline, straight line
  (`Shift` locks horizontal/vertical), freehand pen, 8 colors, 3 widths,
  undo and clear. Copy/download bake the annotations in.
- High-DPI aware: captures the real physical resolution (e.g. 3240×2160 on a
  200% display) instead of a virtualized, magnified image.
- Settings row (Settings → General → “截图”) for the minimize preference.
- Fast: the native helper is compiled once and cached under
  `%USERPROFILE%\.dsh\screenshot-plugin\bin`, so one capture costs ~0.25 s
  (keep) to ~0.5 s (minimize) instead of a several-second PowerShell start.

## Requirements

| | |
|---|---|
| OS | Windows 10/11 |
| DeepSeek Harness | ≥ `0.2.1-rc.5` |
| Runtime | .NET Framework 4.x (`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`) |

## Install from this repository

Ask the Agent in DeepSeek Harness to install the bundle, with the repository as
the target:

```text
install_bundle  target: https://github.com/OWNER/REPO
```

or pin an exact commit (the form the market uses, recommended):

```text
install_bundle  target: https://github.com/OWNER/REPO.git#<40-hex-commit>
```

The plugin is a profile bundle: it loads for every session and survives restarts.

> If an older copy of this plugin is already installed (for example a local
> `link:` or `@local/...` build), disable or remove that bundle first: two
> copies would register the same `/api/dsh-screenshot/*` routes and the second
> one would fail to activate.

## Install from a plugin market

DeepSeek Harness has no official market. The built-in **custom plugin markets**
(experimental, off by default) read index files you add:

1. Plugins page → **More** beside *Experimental plugins* → enable
   **Custom plugin markets**. A **Discover** tab appears.
2. In **Discover**, add this repository's index URL:
   `https://raw.githubusercontent.com/OWNER/REPO/main/index.json`
3. Find **Screenshot** and install it.

`index.json` is generated by `npm run index` (see below) and follows plugin
market index **format 1**.


## Maintainer: publish a new version

1. Bump `version` in `package.json`.
2. Commit and push.
3. Generate the index for the pushed commit and commit it:

   ```bash
   node scripts/build-index.mjs $(git rev-parse HEAD)
   git add index.json && git commit -m "market index for vX.Y.Z" && git push
   ```

   (On Windows PowerShell: `node scripts/build-index.mjs (git rev-parse HEAD)`.)
4. Users get the update from Discover, or by reinstalling the same repository.

The index must stay at the same URL; bump `engines.dsh` only when the plugin
actually needs a newer Harness.

## Layout

| File | Role |
|---|---|
| `index.js` | Host half: `/api/dsh-screenshot/*` endpoints, helper compilation, screen capture |
| `client.js` | Client half: composer button, shortcut, region-picker request, annotation editor |
| `cordis.patch.yml` | Inserts the `dsh-screenshot` bundle row |
| `locale/*.json` | Plugin Manager title and description |
| `icon.svg` | Plugin icon |
| `index.json` | Plugin market index (format 1), generated |
| `scripts/build-index.mjs` | Index generator |
